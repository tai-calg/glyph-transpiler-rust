# Glyph Diagram Editor

GlyphのI/O図と状態遷移図をブラウザで確認・編集し、PNG、SVG、PDFとして出力するための操作ガイドです。

## 起動

### ファイルを指定しない

```bash
python3 glyph.py
```

カレントディレクトリの`.glyph/workspace.glyph`を開きます。ファイルがまだ存在しない場合は、ドア制御のサンプルGlyphを自動作成してエディタへ表示します。

`.glyph/workspace.glyph`が既に存在する場合は上書きしません。前回保存した内容をそのまま開きます。

### 既存ファイルを開く

```bash
python3 glyph.py examples/acceptance/motor_safety.glyph
```

任意の`.glyph`ファイルを指定できます。

## 基本操作

1. ブラウザでGlyph画面が開く。
2. 左側のエディタでGlyphコードを編集する。
3. 編集後約500msでプレビューが更新される。
4. `コンパイル`で保存せず再コンパイルする。
5. `保存`で表示中のGlyphファイルへ保存する。

キーボード操作:

- `Ctrl+Enter` / `Cmd+Enter`: コンパイル
- `Ctrl+S` / `Cmd+S`: 保存

## 表示言語

初期表示は日本語です。画面上部の設定から次を選択できます。

- `日本語`
- `English`

コンパイルエラーと静的解析警告は、内部の英語メッセージを保持したまま、日本語表示と英語表示を切り替えます。

## 図の切替

上部タブで表示を切り替えます。

- `I/O`: `system`宣言から生成したI/O構成図
- `状態遷移`: `machine`宣言と状態遷移関数から生成した状態遷移図

複数の`system`または`machine`がある場合は、図の右上にある選択欄から対象を切り替えます。

## キャンバスの移動

図の空白部分をドラッグすると、キャンバスを上下左右へ移動できます。

状態ノード、I/Oノード、遷移ラベル、ボタンなどをドラッグした場合は、それぞれの編集操作を優先します。キャンバス移動は空白部分だけで開始します。

キャンバスの周囲には可動余白があります。このため、図が上端や左端に隠れている場合でも、親ウィンドウの細いスクロール領域へカーソルを移動せず、図の内部操作だけで表示位置を調整できます。

## 拡大、縮小、全体表示

図のツールバーには次の操作があります。

| 操作 | 結果 |
|---|---|
| `−` | 10%縮小する |
| `＋` | 10%拡大する |
| `全体表示` | 現在の表示領域へ図全体を収める |
| `表示を戻す` | 100%表示と初期位置へ戻す |

倍率範囲は25%から300%です。

キーボード操作:

- `Ctrl+Plus` / `Cmd+Plus`: 拡大
- `Ctrl+Minus` / `Cmd+Minus`: 縮小
- `Ctrl+0` / `Cmd+0`: 表示を戻す

`全体表示`を選んだ状態では、ウィンドウサイズが変わると倍率を再計算します。

`表示を戻す`は倍率と表示位置だけを戻します。ノード配置を自動配置へ戻す`Auto layout`とは別の操作です。

## PowerPointのような配置編集

状態ノードとI/Oノードをドラッグして移動できます。

- 通常ドラッグ: 8pxグリッドへ吸着
- `Shift`を押しながらドラッグ: 1px単位で移動
- ノードを選択して矢印キー: 8px単位で移動
- `Shift`と矢印キー: 1px単位で移動
- `Auto layout`: 保存したノード配置を破棄して自動配置へ戻す

拡大または縮小した状態でも、ドラッグ量を倍率で補正します。例えば50%表示で画面上を50px移動した場合、図の内部座標では100px移動します。

ノード移動後は、遷移線、遷移ラベル、初期遷移線を現在の配置に合わせて再計算します。

## 遷移ラベル

遷移ラベルは、対応する矢印の中央付近へ自動配置します。

配置規則:

1. 矢印経路の中点を求める。
2. 中点から96 CSS px以内を優先して候補位置を探索する。
3. 状態ノードと他ラベルへ重ならない候補を選ぶ。
4. 密集している場合は表示幅を段階的に縮める。
5. 96px以内で解決できない場合だけ、最大160pxまで探索を広げる。

手動操作:

- ラベルをドラッグ: 手動位置へ移動
- ラベルをダブルクリック: 手動位置を解除し、自動配置へ戻す

完全な遷移情報は、ツールチップと図の下にある遷移詳細へ保持します。

## 保存範囲

配置と表示設定はGlyphソースと分離して保存します。

| 設定 | 保存先 | 保存期間 |
|---|---|---|
| 言語 | `localStorage` | ブラウザへ保持 |
| テーマ | `localStorage` | ブラウザへ保持 |
| ノード位置 | `localStorage` | ソースと図ごとに保持 |
| ラベル位置 | `localStorage` | ソースと図ごとに保持 |
| 倍率 | `sessionStorage` | ブラウザタブを閉じるまで |
| キャンバス位置 | `sessionStorage` | ブラウザタブを閉じるまで |

ノードやラベルの配置を変更しても、`.glyph`ソースは書き換えません。

## テーマ

図のツールバーでテーマを選択します。

### White

通常の閲覧・編集用です。

- 白いキャンバス
- 薄いグリッド
- 控えめな影
- 成功・失敗経路を判別できる配色

### Monochrome

会社提出資料、仕様書、白黒印刷用です。

- 白背景
- 黒い線と文字
- 影なし
- 失敗経路は破線
- コピー印刷でも意味が失われにくい表現

## PNG、SVG、PDF出力

表示中の図だけを出力します。左側のGlyphエディタや画面上部の操作UIは含みません。

表示倍率は出力結果へ影響しません。出力処理は、拡大縮小前の図本来の座標を使用します。

### SVG

`SVG`ボタンを押します。

- ベクター形式
- PowerPoint、Illustrator、Figmaなどで拡大しても劣化しない
- 提出資料へ貼り付けた後のサイズ調整に適する

### PNG

`PNG`ボタンを押します。

- 2倍解像度で出力
- Word、Teams、メール、一般的な画像貼り付けに適する

### PDF

`PDF`ボタンを押します。

- 横向きページとして出力
- 会社提出資料、レビュー配布、印刷に適する

出力前に`Monochrome`へ切り替えると、白黒提出用レイアウトのまま保存されます。

## 会社提出資料向けの推奨手順

1. `状態遷移`を開く。
2. `全体表示`で図の全体構成を確認する。
3. ノードをドラッグし、遷移線の交差を減らす。
4. 必要なラベルだけを手動調整する。
5. `Monochrome`へ切り替える。
6. PowerPointで編集を続ける場合は`SVG`を出力する。
7. Wordやメールへ貼る場合は`PNG`を出力する。
8. 完成状態をそのまま提出する場合は`PDF`を出力する。

## デフォルトワークスペース

ファイル未指定で起動した場合の保存先:

```text
<起動したディレクトリ>/.glyph/workspace.glyph
```

最初の起動時だけサンプルコードを生成します。その後に`保存`した内容は次回起動でも維持されます。

新しい初期状態へ戻す場合は、サーバーを停止して`.glyph/workspace.glyph`を削除してから再起動します。

```bash
rm .glyph/workspace.glyph
python3 glyph.py
```

Windows PowerShell:

```powershell
Remove-Item .glyph/workspace.glyph
python glyph.py
```

## 制約

- 配置編集の対象はノード位置とラベル位置です。
- Glyphの状態、遷移、条件、作用はソースコードから生成されます。
- 遷移そのものをマウス操作で追加・削除する機能はありません。
- ブラウザデータを削除すると、保存した配置も消えます。
- 別ブラウザや別PCへ配置を自動同期しません。
- PDFは図面提出用の単一ページ出力です。複数ページの報告書作成はWordまたはPowerPoint側で行います。
