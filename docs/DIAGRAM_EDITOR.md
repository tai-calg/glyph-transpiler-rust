# Glyph Diagram Editor

GlyphのI/O図と状態遷移図をブラウザで確認・編集し、PNG、SVG、PDFとして出力するための操作ガイドです。

## 起動

### ファイルを指定しない

```bash
python3 glyph.py
```

カレントディレクトリの`.glyph/workspace.glyph`を開きます。ファイルがまだ存在しない場合は、ドア制御のサンプルGlyphを自動作成してエディタへ表示します。

`.glyph/workspace.glyph`が既に存在する場合は上書きしません。前回保存した内容をそのまま開きます。

### 既存ファイルを開く

```bash
python3 glyph.py examples/acceptance/motor_safety.glyph
```

任意の`.glyph`ファイルを指定できます。従来の起動方法との互換性は維持されています。

## 基本操作

1. ブラウザでGlyph画面が開く。
2. 左側のエディタでGlyphコードを編集する。
3. 編集後約500msで自動的にプレビューが更新される。
4. `Compile`で明示的に再コンパイルする。
5. `Save`で表示中のGlyphファイルへ保存する。

キーボード操作:

- `Ctrl+Enter` / `Cmd+Enter`: コンパイル
- `Ctrl+S` / `Cmd+S`: 保存

## 図の切替

上部タブで表示を切り替えます。

- `I/O`: `system`宣言から生成したI/Oトポロジ
- `State transitions`: `machine`宣言と状態遷移関数から生成した状態遷移図

複数の`system`または`machine`がある場合は、図の右上にある選択欄から対象を切り替えます。

## PowerPointのような配置編集

状態ノードとI/Oノードをドラッグして移動できます。

- 通常ドラッグ: 8pxグリッドへ吸着
- `Shift`を押しながらドラッグ: 1px単位で移動
- ノードを選択して矢印キー: 微調整
- `Auto layout`: 保存した配置を破棄して自動配置へ戻す

ノード移動後は、遷移線、遷移ラベル、初期遷移線を現在の配置に合わせて再計算します。

配置はブラウザの`localStorage`へ保存されます。保存単位は次の組み合わせです。

- Glyphソースの内容
- I/O図または状態遷移図
- 選択中の`system`または`machine`

Glyphコード自体の保存とは別です。ノード配置だけを変更しても`.glyph`ソースは書き換えません。

## テーマ

図のツールバーでテーマを選択します。

### White

通常の閲覧・編集用です。

- 白いキャンバス
- 薄いグリッド
- 控えめな影
- 成功・失敗経路を判別できる配色

### Monochrome

会社提出資料、仕様書、白黒印刷用です。

- 白背景
- 黒い線と文字
- 影なし
- 失敗経路は破線
- コピー印刷でも意味が失われにくい表現

## PNG、SVG、PDF出力

表示中の図だけを出力します。左側のGlyphエディタや画面上部の操作UIは含みません。

### SVG

`SVG`ボタンを押します。

- ベクター形式
- PowerPoint、Illustrator、Figmaなどで拡大しても劣化しない
- 提出資料へ貼り付けた後のサイズ調整に適する

### PNG

`PNG`ボタンを押します。

- 2倍解像度で出力
- Word、Teams、メール、一般的な画像貼り付けに適する

### PDF

`PDF`ボタンを押します。

- 横向きページとして出力
- 会社提出資料、レビュー配布、印刷に適する

出力前に`Monochrome`へ切り替えると、白黒提出用レイアウトのまま保存されます。

## 会社提出資料向けの推奨手順

1. `State transitions`を開く。
2. ノードをドラッグし、遷移線の交差を減らす。
3. `Monochrome`へ切り替える。
4. PowerPointで編集を続ける場合は`SVG`を出力する。
5. Wordやメールへ貼る場合は`PNG`を出力する。
6. 完成状態をそのまま提出する場合は`PDF`を出力する。

## デフォルトワークスペース

ファイル未指定で起動した場合の保存先:

```text
<起動したディレクトリ>/.glyph/workspace.glyph
```

最初の起動時のみサンプルコードを生成します。その後に`Save`した内容は次回起動でも維持されます。

新しい初期状態へ戻す場合は、サーバーを停止して`.glyph/workspace.glyph`を削除してから再起動します。

```bash
rm .glyph/workspace.glyph
python3 glyph.py
```

Windows PowerShell:

```powershell
Remove-Item .glyph/workspace.glyph
python glyph.py
```

## 制約

- 配置編集の対象はノード位置です。Glyphの状態、遷移、条件、作用はソースコードから生成されます。
- 遷移そのものをマウス操作で追加・削除する機能はありません。
- ブラウザデータを削除すると、保存したノード配置も消えます。
- 別ブラウザや別PCへ配置を自動同期しません。
- PDFは図面提出用の単一ページ出力です。複数ページの報告書作成はWordまたはPowerPoint側で行います。
